## 배경 · 목적

**1. 상단 [콘텐츠 맵] 버튼이 관리되지 않는 페이지로 연결됨**

현재 클래스 웹 상단에 고정된 `콘텐츠 맵` 버튼은 **예전 에어테이블 페이지**를 열며, 이 페이지는 관리 주체가 없어 실제 챌린지 목록과 어긋난 상태임.

**2. 전체 챌린지를 한눈에 보고 싶다는 요청**

교사로부터 "아하오호에 어떤 챌린지가 있는지 손쉽게 확인하고 싶다"는 요청이 접수됨. 현재는 **큐레이션을 만드는 도중에만** 전체 챌린지를 볼 수 있어, 둘러보려면 큐레이션 만들기에 들어가야 함.

**3. 문제 해석**

새 화면을 처음부터 만들 필요는 없음. 큐레이션 만들기 모달이 이미 **검색·필터·정렬이 붙은 전체 챌린지 목록**을 갖고 있으므로, 그 목록을 **화면 폭으로 넓혀 독립 화면으로 꺼내면** 요청의 대부분이 해결됨. 챌린지 상세는 별도 일감(`챌린지_상세보기모달_전체화면_개선`)에서 만든 모달을 그대로 연결함.

**4. 목적**

큐레이션을 만들지 않고도 **전체 챌린지를 둘러보고 수업에 맞는 챌린지를 찾을 수 있게** 함. 상위 맥락은 `1pager_클래스_정식출시.md`의 교사 여정 4단계 중 **② 수업 준비** 단계 병목 제거.

**5. 사전 논의된 개발 스펙**

큐레이션 생성. 큐레이션은 **`큐레이션 만들기` 버튼을 통해서만** 만들 수 있고, 콘텐츠맵은 열람 전용임.

## 레이아웃 기준

기준 해상도 **1280×800** (LG 그램 14 / 1920×1200 @150%), 브라우저 배율 100%. 실측값은 이 기준의 프로토타입에서 측정한 값임.

| 영역 | 크기 | 구성 |
|---|---|---|
| 상단 바 | 높이 **66px** | 로고 · 공지사항 · 이용 가이드 · 로그아웃 (기존 `콘텐츠 맵` 버튼은 제거) |
| 사이드바 | 폭 **264px** | 클래스 선택 · 아하오호 갤러리 · **콘텐츠맵** · 멤버관리 · 공지사항 |
| 본문 | 나머지 (**1001px**, 좌우 여백 34px → 콘텐츠 폭 **933px**) | 3~10 |

**카드 그리드**

- 한 줄 **6열**, 카드 폭 **141px**, 간격 16×18px
- 썸네일 **4:5**(141×176px) — 원본 챌린지 썸네일의 제작 규격이 4:5이고 큐레이션 만들기 모달의 카드(149×187)와 같은 비율
- 챌린지명은 **2줄 높이를 미리 확보**(최대 24자) → 카드 높이가 **249px로 일정**해짐
- 1280×800에서 **2행 × 6열 = 12장이 스크롤 없이** 보임

정책 : 열 수를 6으로 둔 이유는 두 가지임. ① 5열이면 카드 폭이 175px로 큐레이션 만들기 모달의 실제 카드(149px)보다 26px 커져 두 화면의 카드 크기가 어긋남 ② 4:5 비율에서 5열은 카드 높이가 288px이 되어 1280×800에 2행이 66px 부족함. 요구사항이 "**최소** 2행 × 5열"이므로 6열은 이를 넘어서 만족함
정책 : 챌린지명 줄 수에 따라 카드 높이가 달라지면 어떤 챌린지가 앞에 오느냐에 따라 2행 여부가 바뀜. 최대 글자 수 기준으로 높이를 먼저 확보해 목록이 흔들리지 않게 함

## 11) 카드 클릭 → 챌린지 상세 보기 모달 (challenge_detail)

![카드 클릭 시 모달](번호%20표기%20화면/callout_카드클릭_모달.png)

카드 클릭 시 **챌린지 상세 보기 모달을 전체 화면으로** 띄움. 화면 분할이나 우측 패널 방식은 사용하지 않음.

- 모달의 구성·동작은 별도 일감 기획서(`챌린지_상세보기모달_전체화면_개선/기획서_챌린지상세보기_전체화면.md`)를 그대로 따름
- 진입 시 기본 탭은 **아하오호 화면 보기**(모달의 기존 기본값 유지)
- 닫으면 콘텐츠맵 목록으로 돌아오며, **검색어·필터·정렬·스크롤 위치가 유지**됨
- **예외 처리 :** 모달 안 수업 정보 탭의 추천 챌린지를 누르면 그 챌린지 모달이 겹쳐 열림(모달 기획서의 수업 정보 12번). 겹친 모달을 모두 닫으면 콘텐츠맵으로 돌아옴
- **참고 사항 :** 요구사항에는 "노션처럼 화면 분할 후 우측에 상세뷰"가 있었으나, 같은 모달을 이미 큐레이션 화면·큐레이션 만들기에서 쓰고 있으므로 콘텐츠맵만 다른 방식으로 열면 화면마다 상세 보기가 달라짐. 전체 화면 모달로 통일함
- **참고 사항 :** 콘텐츠맵에서는 **수업 정보**가 중점이지만 탭 순서·기본 탭은 바꾸지 않음. 어느 탭이 먼저인지에 대한 니즈가 교사마다 갈리고, 진입 경로마다 기본 탭이 다르면 같은 모달인데 매번 다른 화면이 열리는 것으로 읽힘

## 7) 필터 (filter)

큐레이션 만들기 모달의 필터를 **그대로 가져오고 난이도 행만 추가**함.

| 번호 | 행 | 값 | 구분 |
|---|---|---|---|
| 7-1 | 카테고리 | 소리와 음악 · 디지털과 미디어 · 사람과 세상 · 과학과 자연 · 몸과 감각 · 놀이와 게임 · 수와 생각 · 그림과 만들기 (8종) | 기존 |
| 7-2 | 학년 | 1 · 2 · 3 · 4 · 5 · 6 | 기존 |
| 7-3 | 과목 | 과학 · 국어 · 도덕 윤리 · 미술 · 사회 · 수학 · 실과 · 실과 기술가정 정보 · 영어 · 음악 · 체육 보건 (11종) | 기존 |
| 7-4 | **난이도** | **1 · 2 · 3 · 4 · 5** | **신규 · 동반 변경** |
| 7-5 | 행별 초기화 | 각 행 우측 `↺` | 기존 |
| 7-6 | 결과 없음 안내 | 일러스트 + 한 줄 문구 | 기존 |

- 각 행 안에서 **다중 선택**(OR), 행과 행 사이는 **AND**
- 5번 검색창과도 AND로 함께 적용
- `큐레이션 하지 않았던 챌린지만 보기` 체크박스는 **콘텐츠맵에 두지 않음** — 큐레이션 생성 맥락의 조건이므로
- 참고 사항 : 난이도 표기는 별(★)이 아니라 숫자 `1~5`
- 예외 처리 : 조건에 맞는 챌린지가 0건이면 목록 대신 안내 문구를 출력(`조건에 해당되는 챌린지가 없습니다.`)

# 동반 변경 — 큐레이션 만들기 모달

**화면 기획서 링크**

**난이도 필터 추가 — 현행 3행(카테고리 / 학년 / 과목) 아래에 난이도 1·2·3·4·5 행 추가**

- 칩 형태 · 다중 선택 · 행 우측 초기화(`↺`)는 기존 3행과 동일
- 표기는 숫자 `1~5`, 행 순서는 맨 아래 (콘텐츠맵 7-4와 동일한 규칙)
- 큐레이션 만들기 모달의 정렬 기준 **'등록순'** 추가 & 기본값을 등록순으로 변경 필요.

**empty state 문구 변경 필요 - 검색어 / 필터 조건에 맞는 챌린지가 0건일 경우, 문구 변경 필요**

- 현재: `선택된 필터에 해당되는 챌린지가 없습니다.`
- 변경 필요: `조건에 해당되는 챌린지가 없습니다.`

## 인수 기준 (QA 확인 항목)

1. 기준 해상도 1280×800 · 브라우저 배율 **100%** 에서 모든 UI가 잘림 없이 표시되고 가로 스크롤이 발생하지 않음
2. 사이드바 `콘텐츠맵` 클릭 시 **같은 탭**에서 화면이 전환되고, 현재 위치가 사이드바에 표시됨
3. 상단 바의 기존 `콘텐츠 맵` 버튼이 제거되어 에어테이블 페이지로 가는 경로가 남아 있지 않음
