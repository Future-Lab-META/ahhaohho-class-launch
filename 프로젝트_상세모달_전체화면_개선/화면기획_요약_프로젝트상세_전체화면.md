**게시물 상세보기 — 전체 화면**

Page ID : `curation_gallery` / 경로 : 아하오호 뮤지엄 화면 > 큐레이션 갤러리 화면
조건 : 큐레이션 갤러리에서 게시물 카드 클릭 시. 새 창·새 탭 없이 같은 탭에서 전체 화면으로 전환

**왜 바꾸나**
"이미지·영상이 작게 보인다"는 VOC가 교사로부터 반복 접수되고, 현장에서 **배율 축소(90%)·F11·화면 캡쳐 후 확대** 같은 우회 사용이 관찰됨. 특히 화면을 캡쳐해 OS 이미지 뷰어로 확대하는 것은 제품 안에서 해결이 안 되어 밖으로 나간 신호(부가로 아이 작품이 교사 개인 기기에 사본으로 남음). → **우회 없이 기본 상태에서 크게 보이도록** 하는 것이 이 일감의 목적.

**무엇이 바뀌었나**
모달 안에 4:5로 고정·축소해 보여주던 게시물을 **전체 화면**으로 옮기고, 미디어를 **원본 비율 그대로 영역에 꽉 차게** 표시. 구성요소 1-1~1-16은 그대로 두고 위치만 3개 영역(상단 바 56px / 미디어 스테이지 / 우측 정보 레일 320px)으로 재배치했으며, 확대(1-17)와 조작 안내(1-18)가 추가됨. 기준 해상도 1280×800·배율 100%에서 잘림이 없어야 하며, 배율 축소·F11 같은 우회 조작을 전제하지 않음.

> 번호 표기 화면 : `번호 표기 화면/callout_all.png` — 1-1~1-18 전체 (1280×800 기준, 2배 캡쳐)
> 모든 번호가 한 화면에 나오도록 영상 + 미디어 2장 + 숨겨진 댓글 + 고정 상태를 모두 갖춘 케이스로 캡쳐
> ※ 재생성이 필요하면 같은 폴더의 `_make_callouts.py` 실행 (프로토타입에 번호를 얹어 헤드리스 크롬으로 추출 — 번호 위치는 레이아웃에 맞춰 자동 계산)
> 상세 규칙·정책·예외 처리 : `변경기획_프로젝트상세_전체화면.md`
> 인터랙티브 시안 : `시안_프로젝트상세_전체화면.html`

**상단 바** (높이 56px)

1-1) 큐레이션 정보 — `아하오호 갤러리 > {큐레이션명} > {챌린지명}`. **[변경]** 각 항목 클릭 이동 추가 (갤러리 복귀 / 큐레이션 화면 / 챌린지 상세 모달). 출력 3가지 케이스는 기존과 동일
1-2) 숨겨진 댓글 숨김 해제 — **[변경]** 위치만 상단 바로. **1-9-1로 숨긴 댓글**이 있을 때만 노출, 일괄 복원 후 버튼 미노출
1-5) 닫기 — **[변경]** 모달 외부 → 상단 바 우측 끝. 좌측 끝 `←`(뒤로), `ESC` 키 지원

**미디어 스테이지** (화면 − 상단바 − 레일, 좌우 여백 92px)

1-13) 게시물 이미지/영상 — **[변경·핵심]** 4:5 고정 → **원본 비율 유지 + 영역 맞춤(contain)**. 원본 해상도보다 확대하지 않음. 1280×800에서 가용 폭 776px
1-14) 영상 길이 표기 — **[유지]** 미디어 좌상단. `분:초`, 15초 이하만 업로드 가능. 확대 시 함께 커지지 않음
1-15) 미디어 이동 화살표 — **[변경]** 이미지 내부 → **이미지 바깥 하단**. 조건 `uploadFiles.length > 1`
1-16) 페이지 인디케이터 — **[변경]** 1-15와 한 묶음(`◀ ● ● ▶`, 44px). 점 클릭으로 직접 이동
1-7) 다음·이전 게시물 이동 — **[변경]** 모달 외부 → **스테이지 좌우 64px 큰 화살표** + 라벨. 키보드 `←` `→`. 이동 규칙(마지막 게시물 → 다음 큐레이션 첫 게시물)은 기존과 동일
1-17) 미디어 확대 — **[신규]** 휠·트랙패드 핀치로 커서 위치 기준 1~3배, 드래그 이동, 더블클릭·게시물 전환 시 초기화. 확대 대상은 이미지·영상만(화살표·뱃지·안내는 고정). 영상은 재생 중에도 확대·이동 가능
1-18) 조작 안내 — **[신규]** 스테이지 좌하단에 아이콘 + 문구를 **항목별 한 줄씩 세로 나열**해 상시 노출(휠·핀치로 확대 / 드래그로 이동 / 더블클릭하면 원래 크기 / ←→ 작품 넘기기 / ESC 닫기). 확대와 키보드 조작은 단서가 없으면 발견 불가하므로 상시 노출

**우측 정보 레일** (폭 320px) — 번호 없는 영역 정의. **3단 구조**: [고정 헤더] 1-3·1-4 / [스크롤] 1-6 → 댓글 수 → 1-7~1-9 / [고정 푸터] 1-10·1-11. 본문 500자·댓글 다수도 레일 안에서만 스크롤되고 미디어는 고정
1-3) 작성자 정보 — **[유지]** 프로필 이미지·닉네임·멤버 태그(이름, 미입력 시 미노출)·작성일
1-4) 더보기 메뉴(···) — **[유지]** 메시지 보내기 / 멤버 정보 보기 / 게시물 숨기기
1-6) 게시물 내용 — **[변경]** 출력 규칙(최대 500자) 동일, **폰트 16px/600으로 상향**(댓글 13px/400과 위계 구분)
1-8) 댓글 내용 — **[유지]** 전문 노출. **아이(게시물 작성자)가 앱에서 숨긴 댓글**은 내용 대신 안내 문구 표시 (1-2 복원 대상 아님)
1-9) 댓글 더보기(⋮) — **[유지]** 1-9-1 댓글 숨기기 — **선생님(관리자)이 뮤지엄에서 숨김**, 확인 모달 없이 즉시 처리, 아이들 앱에는 영향 없음, 1-2로 일괄 해제 / 1-9-2 멤버 정보 보기
1-10) 게시물 고정 상태 표시 — **[변경]** 위치만 레일 하단 좌측. 고정 정책(로컬 state, 서버 미저장, 해제 시 `createdAt DESC`)은 기존과 동일
1-11) 챌린지 상세 보기 — **[유지]** 위치만 레일 하단 우측. 1-1 챌린지명과 이동 대상 동일 — 중복 경로 의도적 유지

> 1-12는 기존 기획서에도 없는 결번. 번호 재정렬하지 않음
