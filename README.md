# 아하오호 클래스 정식 출시 — 기획 산출물

클래스 웹(교사용) 정식 출시 관련 기획 문서와 프로토타입.

**👉 [산출물 목록 페이지](https://future-lab-meta.github.io/ahhaohho-class-launch/)**

## 포함 내용

| 구분 | 산출물 | 설명 |
|---|---|---|
| 전체 배경 | 클래스 정식 출시 1-pager | 목표·KR, 배경, 가설과 검증 전략, 원칙, KPI |
| ① 프로젝트 상세 모달 → 전체 화면 | 기획서 | 배경·목적, 구성요소 1-1~1-18, 레이아웃 수식, 예외 처리, 인수 기준 |
| | 인터랙티브 시안 | 작품 넘기기, 휠·핀치 확대, 미디어 2장, 영상, 본문 500자, 댓글 스크롤 |
| ② 챌린지 상세 보기 모달 → 전체 화면 | 기획서 | 배경·목적, 공통 1~8 및 화면별 구성요소, 레이아웃 수식, 예외 처리, 인수 기준 |
| | 인터랙티브 시안 | 아하오호 화면 보기 탭 + 수업 정보 탭, 앱 화면 구성 유지, 4단계 이동, 아하's Pick, 아하 탭, 휠·핀치 확대, 수업 정보 탭, 가이드 사운드, 추천 챌린지 모달 겹침 |
| ③ 콘텐츠맵 리뉴얼 | 인터랙티브 시안 | 검색, 필터(카테고리·학년·과목), 정렬 4종, 카드 클릭 시 챌린지 상세 보기 모달 |
