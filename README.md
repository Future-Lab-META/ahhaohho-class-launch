## 참고

- 프로토타입의 이미지·영상은 실제 프로젝트 리소스이며, 본문·댓글·큐레이션명·챌린지명은 레이아웃 검증용 예시
- 멤버 실명이 노출되는 기존 기획서·현행 화면 캡쳐는 이 저장소에 포함하지 않음 (로컬 작업 폴더에만 보관)
- 아하오호 화면 보기 일감은 기획서 작성 후 추가 예정
- 번호 표기 화면 재생성: `프로젝트_상세모달_전체화면_개선/번호 표기 화면/_make_callouts.py`
